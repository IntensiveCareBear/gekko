Persona fleet: Multiple Gordon instances run concurrently with different personas. Each consumes from kahuna.ingest.public, generates an LLM proposal, and publishes to gordon.strategies.proposed. The Executive Core's Consensus Engine buffers BUY proposals within a short time window and consolidates competing persona opinions into a single weighted order. SELL proposals bypass consensus and execute immediately. The Adaptive Allocator (Phase 4) learns per-persona win rates via EWMA and adjusts consensus weights over time.
